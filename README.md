# 景仁宫 · 开发者版

古风自律番茄钟「景仁宫 · 岂容你放肆」的**开发者版**，内置调试面板，可快速跳转状态、预览剧情、试听配音。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 轻量版（约 1.05 MB），不含预生成配音，使用浏览器内置语音朗读，加载快 |
| `full.html` | 完整版（约 9.4 MB），内联全部 AI 配音与写实立绘，声音最完整 |
| `.nojekyll` | 关闭 Jekyll，保证 GitHub Pages 直接发布静态文件 |

两个文件均为**单文件网页**，无外部依赖，双击即可在任意浏览器打开，也可直接部署到任意静态托管。

## 开发者面板（DEV）

打开页面后，标题下方常驻「DEV 面板」按钮，点击可收起 / 展开。

- **数值**：直接设定臣服人数、本班炷数、累计炷香，或 `+1 / −1` 臣服
- **时间**：倍速（×1/×2/×4/×8）、立即结束当前计时、自动开始
- **剧情**：预览开头剧情、臣子臣服、登基（含勤政 / 享乐分支）、鞭笞动画、监工大臣、镜头推进
- **声音**：触发宫钟、试听太监 / 宫女台词、试听各角色音色
- **数据**：填充 7 天假数据、切换皇子道 / 女官道、清空存档重新择道

面板状态每秒刷新一次，可直接观察 `S` 状态、职分、阶段、香时与剧情进度。


## 分心守望

燃香开始时，程序会先弹出「守望允准」卡，取得你的许可后才开始计时：

- **离开监视**：燃香期间切走页面、切到别的窗口超过阈值（默认 2 秒），立即响铃并在系统通知里催你回来；回到页面即弹出鞭笞界面。人刚走的那一瞬间就截屏取证，回来领罚时看到的是分心期间的真实画面。
- **截屏留证（可选）**：勾选后浏览器会弹出共享屏幕授权，只在命中分心时于本机截一张图作为罪证，不上传。
- **设置**：右侧「数据」页可随时开关守望、修改判定阈值、开启/关闭截屏留证与「分心即作废」。

浏览器沙箱无法读取你具体打开了哪个软件，也无法把窗口置顶到其他应用之上。需要**真正识别抖音 / 快手 / 哔哩哔哩并把鞭笞窗口强制置顶**，请使用配套的 Windows 桌面版（见 `jingrengong-desktop.zip` 内的说明）。

## 视觉巡检（新）

守望允准后，燃香期间每 **20 秒**自动执行一轮静默巡检（页面必须处于前台），所有画面**仅在本机分析、不落盘、不上传**：

- **屏幕巡检**：从屏幕共享流静默抓帧——
  - 帧差启发式（默认，离线可用）：连续约 2 分钟画面无变化 → 判定「挂机发呆」，提醒并记入簿册；
  - **OCR 关键词增强**（设置中可选，需联网加载一次词库，约 20MB）：识别截图文字，命中 `抖音 / bilibili / 快手 / 微博 / 王者荣耀…` 黑名单连续 2 次 → 鞭笞。
- **摄像头守望**（需单独授权，可只开这一个）：
  - 运动启发式（默认，离线可用）：连续 100 秒镜头前毫无动静 → 判定离席；
  - **人脸姿态增强**（设置中可选，联网加载 MediaPipe 模型）：镜头前连续 2 帧无人 → 离席；头部持续偏转 → 视线偏离；双眼闭合 → 打瞌睡，均按连续命中次数判罚。
- **判罚**：任一通道连续命中达到次数即复用现有鞭笞流程（响铃、语音、鞭笞卡、留证），判罚后冷却 1 分钟防连环罚；若开启「分心即作废」，鞭笞卡上会出现「此香作废」按钮。
- **调试**：DEV 面板「分心守望」区可手动巡检一次、开关摄像头，实时查看帧差与命中计数；控制台另有 `__JRG_WATCH__.state()` / `__JRG_WATCH__.patrol(true)`。
- **隐私**：摄像头与屏幕画面全程仅本机分析；OCR / 人脸两个增强组件来自 jsDelivr CDN，属可选加载，不开启则完全不发起任何外部请求。

## 玩法

- 一炷香 25 分钟，四炷香为一班，班满一位臣子归心
- 二十臣尽服后登基 / 登极，可选择勤政或享乐分支
- 中途分心作废，此香不计功次，并触发监工鞭笞
- 皇子道 / 女官道两套人物、立绘、台词与配音（男女分道、区分老少）

## 部署

仓库根目录已含 `.nojekyll`，在 GitHub 仓库 **Settings → Pages** 中选择 `Deploy from a branch`，分支 `main`、目录 `/ (root)` 即可。

## 说明

- 进度保存在浏览器 `localStorage`，清空浏览器数据会重置。
- 完整版体积较大，移动端首次加载稍慢；网络较慢时建议使用 `index.html`。
